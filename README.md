# Driftmap

Zero-cost city exploration game and cinematic journey replay — LAYOVER 2026.

- **Explore** — personality-driven missions, fog-of-war reveals, photo completions
- **Remember** — map, timeline, and mood views over your journey
- **Replay** — "Play My Journey": your run as a skippable film

Built with Next.js, TypeScript, Tailwind, MapLibre, and IndexedDB. No backend, no accounts, no required API keys.
